# Translation glossary (Vietnamese → English)

Use these terms consistently in every translation task (T-005 … T-009). Terms already in English in the source (Host, Viewer, Session, OTP, aggregate, use case, port, adapter, invariant names, error codes…) stay exactly as they are.
